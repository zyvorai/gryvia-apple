Download

From a download to a working fleet.

Install the notarized app, start your 30-day trial, add a Mac and call a model through the OpenAI-style endpoint.

1. Download and verify

You need: an Apple silicon Mac on macOS 15 or later. A second Mac is optional.

Download Gryvia-0.5.2.dmg and its .sha256 file from the release page. The DMG is Developer ID signed and notarized.

shasum -a 256 -c Gryvia-0.5.2.dmg.sha256

Free 30-day trial key: sales@zyvor.dev. Licences are at zyvor.dev/buy.

2. Install and open

Open the DMG and drag Gryvia.app to Applications. The first launch shows a short Welcome; reopen it from Help. Paste an admin token once; it is kept in your login Keychain. Press Run demo job to see admission, a lease and a result.

⌘K opens a command palette, ⌘1…⌘0 switch panes, and clicking an underlined term such as reserved explains it. Open a queued job to see why it is waiting. Reservations are bookkeeping, not a GPU meter.

3. Add a Mac

Use Add a Mac in the app or the web dashboard to create a single-use join code (valid 15 minutes). Enter it on the new Mac to enrol it; no config edit or restart is needed. A Mac's token can be revoked later. A control plane that other Macs reach must use HTTPS; plain HTTP is accepted only for loopback.

Each Mac has an owner policy: always, only when its owner is away, or paused, with battery, Low Power Mode and call guards.

4. Call a model

Once a model is deployed its endpoint is OpenAI-style. Use a tenant token:

curl -s http://127.0.0.1:8443/v1/chat/completions \
  -H "Authorization: Bearer $GRYVIA_TENANT_TOKEN" -H 'Content-Type: application/json' \
  -d '{"model":"my-llama","messages":[{"role":"user","content":"Say hi"}]}'

Add "stream": true for server-sent events. Model servers listen on the worker's loopback only, and your platform token never reaches them. With replicas the gateway sends each request to the replica with the fewest in flight and tries one other before returning 502. Deployments keep their memory reservation until stopped; idle eviction is opt-in.

When something is wrong

SymptomCheck
Deploy stays queuedIs the Mac online, not drained, with enough free GiB and the model on it?
Request returns 503The model is not deployed, was evicted, or its Mac is offline.
Request returns 502The replica failed; with replicas the gateway already tried one other.
Gatekeeper blocks the appVerify the checksum; the 0.5.2 DMG is notarized, so a block usually means a damaged download.

Honest limits

One GPU per Mac; GPU utilisation is device-wide, not per job; reservations are bookkeeping; energy is an estimate; runtimes are not sandboxed, so only enrol Macs you would let an admin run code on. Replicas across two physical Macs are not yet measured. See SECURITY.md.
